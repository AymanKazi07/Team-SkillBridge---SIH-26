# SkillBridge - AI-Powered Academia-Industry & AYUSH NEP-2020 Ecosystem

SkillBridge is a national academia-industry portal designed to align with the National Education Policy (NEP) 2020 and the Ministry of AYUSH[cite: 2]. It serves as a unified gateway to connect students, academicians, and industry leaders by bridging skill gaps through AI-powered assessments and verified academic credit tracking[cite: 1, 2]. 

## 🌟 Project Overview

The platform automates skill profiling across specialized domains including Technical Engineering, Management, Law, and AYUSH (Ayurveda, Yoga, Unani, Siddha, Homeopathy)[cite: 1, 2]. By integrating with the Academic Bank of Credits (ABC) and utilizing APAAR ID verification, SkillBridge creates a seamless ecosystem for career development, certified learning, and talent recruitment[cite: 2].

## 🚀 Key Features

### For Students & Researchers
* **AI-Powered Skill Assessment:** Evaluates user competence based on uploaded skills, projects, GitHub repository telemetry, and research publications[cite: 2].
* **APAAR ID Integration:** Verifies student profiles and synchronizes earned NEP 2020 credits directly to their Academic Bank of Credits (ABC)[cite: 1, 2].
* **Personalized Career Roadmaps:** Generates step-by-step upskilling workflows mapped to National Higher Education Qualifications Framework (NHEQF) standards[cite: 2].
* **Opportunities Access:** Allows students to apply directly for skill-matched internships and verified placements using their APAAR portfolio[cite: 2].

### For Academicians & Faculty
* **Course Publishing:** Enables faculty to create and publish deadline-based accredited courses[cite: 1, 2].
* **Timed Assessments:** Supports the creation of interactive, timed quizzes that grant NEP credits upon successful completion[cite: 2].
* **Research Collaboration:** Facilitates participation in Faculty Development Programs (FDPs) and industry-sponsored clinical research[cite: 2].

### For Industry & R&D Labs
* **Targeted Recruitment:** Allows industries to post domain-specific internships and placements mapped to required skills[cite: 1, 2].
* **Verified Talent Pools:** Provides access to auto-shortlisted candidates backed by AI competency scores and verified APAAR academic records[cite: 2].

## 💻 Tech Stack

* **Frontend Integration:** HTML5, JavaScript, and Tailwind CSS for a responsive, dark-mode-enabled UI.
* **Backend Framework:** FastAPI (Python) for handling assessment endpoints and business logic.
* **Data Validation:** Pydantic for strict data typing and request modeling[cite: 1].
* **Server & Deployment:** Uvicorn as the ASGI web server and Mangum for AWS Lambda compatibility[cite: 1].

## ⚙️ Installation & Setup

1. **Launch the Frontend:**
   Simply double-click or open the `index.html` file in any modern web browser to access the application interface locally[cite: 1].
